# Self-hosted fonts

Manrope and DM Sans are licensed under the SIL Open Font License; see the adjacent license files.
Source: Google Fonts (fonts.gstatic.com), retrieved 2026-10-17. Latin subsets only.
Static WOFF2 instances generated with fontTools 4.67.0 from the Google Fonts variable WOFF2 files, pinning wght to the filename value and all other axes to their defaults.
Manrope: 600, 800. DM Sans: 400, 600, 700. CSS uses font-display: swap; only Manrope 600 is preloaded. Intermediate 650 declarations map to 600.
